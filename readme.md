
# VeloPlan 🚴‍♂️📱

VeloPlan is a React Native app built with Expo for cyclists who want a personal library of structured bike workouts.  
Create and store multiple training sessions using a simple text-based workout language, visualize them with charts, and export them to Garmin and other platforms.  

---

## ✨ Features
- Create and manage multiple workouts
- Text-based workout scripting (warmup, intervals, cooldown, etc.)
- Visualize workouts with charts
- Export workouts to Garmin-compatible formats
- Personal library of training sessions

---

## 📲 Tech Stack
- [React Native](https://reactnative.dev/)  
- [Expo](https://expo.dev/)  
- [TypeScript](https://www.typescriptlang.org/)  
- [Recharts](https://recharts.org/en-US/) (charts)  
- [Shadcn/ui](https://ui.shadcn.com/) (UI components)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) >= 18
- [Expo CLI](https://docs.expo.dev/get-started/installation/)

### Installation
```bash
# clone the repository
git clone https://github.com/your-username/veloplan.git

# go to project directory
cd veloplan

# install dependencies
npm install
````

### Running the app

```bash
# start expo
npx expo start
```

You can then open the app on your device using the Expo Go app (iOS/Android) or an emulator.

## 📖 Example Workout Script

Example of how a workout can be described in VeloPlan:

```
Warmup
- 10m Z1 HR intensity=warmup

Main Set
- 70km freeride Z2 HR intensity=active

Cooldown
- 10m Z1 HR intensity=cooldown
```
